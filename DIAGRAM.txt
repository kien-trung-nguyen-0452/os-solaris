PROCESS EXECUTION FLOW:

1. ProcessManager creates Process objects
   │
   ▼
2. Processes are initialized with arrival times, priorities, burst times
   │
   ▼
3. SchedulingThread wraps Scheduler (RoundRobin or Priority)
   │
   ▼
4. Scheduler.addProcess() → Process state: NEW → READY
   │
   ▼
5. Scheduler.selectNextProcess() → selects process from ready queue
   │
   ▼
6. Dispatcher.dispatch() → Process state: READY → RUNNING
   │
   ▼
7. Process.execute() → executes for time quantum
   │
   ├─→ If completed: Dispatcher.complete() → TERMINATED
   │
   └─→ If not completed: Dispatcher.preempt() → READY (back to queue)

═══════════════════════════════════════════════════════════════════════════════

THREAD EXECUTION:

Main Thread
   │
   ├─→ Creates RoundRobinThread
   │      │
   │      └─→ Runs RoundRobinScheduler.schedule()
   │
   └─→ Creates PriorityThread
          │
          └─→ Runs PriorityScheduler.schedule()

Both threads run concurrently and independently!
